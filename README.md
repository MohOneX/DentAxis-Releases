# DentAxis — Official Releases

This repository hosts **official Windows installers** and **auto-update metadata** for [DentAxis](https://github.com/MohOneX/DentAxis) dental clinic management software.

## What this repo contains

- Windows installer (`.exe`)
- `latest.yml` (used by the app to check for updates)

## What this repo does NOT contain

- Source code
- License keys
- Patient or clinic data

The DentAxis application source is maintained in a **private** repository.

## Download

Go to **[Releases](https://github.com/MohOneX/DentAxis-Releases/releases)** and download the latest `DentAxis Setup X.X.X.exe`.

## Auto-updates

Installed DentAxis apps check this repository for new versions. When a new release is published, users are notified in the app and can update from **My Account → Updates**.
